# UDG MVP验证记录

- 日期：2026-05-08
- 范围：待机UI -> 下落开局 -> 碰撞分裂/销毁 -> 奖池结算 -> 金币持久化

## 已接入链路

- 待机/运行两态切换：`grid_root`、`drop_btn`、`bottom_panel` 与 `game_container`、`reward_pool` 对切。
- 启动开局：点击 `drop_btn` 后读取放置框球并生成运行态球体与方块。
- 碰撞流程：球与方块接触时扣血；方块血量归零销毁并加金币；球耗尽后触发分裂或销毁。
- 奖池结算：球体进入 `reward_pool` 且纵向速度向下时结算，单球仅一次。
- 单局结算：场内球体清空后统一结算金币并写回本地存档。
- 本地存档：`player_gold`、`total_buy_count`、`grid_ball_list`、`level_unlock_list` 已落盘。
- 容错：静止超时回收、速度上下限、出界销毁、关键流程日志。

## 说明

- 当前环境未接入自动化 PlayMode 测试框架，以上结果基于代码链路自检与静态检查（无 lints）。
